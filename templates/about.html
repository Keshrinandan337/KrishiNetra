🌱 About KrishiNetra 🌱

KrishiNetra is an AI-powered agriculture assistant designed to assist farmers by providing accurate and timely information for crop management.

  • 🌿 AI-powered plant disease detection
  • 🍃 Smart farming and Weather-based assistant
  • ⚡ Integrated diseases information library
  • 🤖 AI chatbot for smart agricultural assistance

Technologies Used

🌶 Flask

A Lightweight Python web framework used to build the backend architecture of KrishiNetra.

Handles image uploads, AI model integration,prediction processing, and dynamic routing.

🕸 MobileNetV2

Deep Learning CNN architecture optimized for fast and accurate plant disease detection.

Trained on agricultural image datasets for real-time prediction and classification.
