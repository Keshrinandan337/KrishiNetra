🌱 KrishiNetra

KrishiNetra is an AI-powered smart agriculture platform developed to help farmers detect plant diseases accurately using Deep Learning, Computer Vision, weather-based assistance, and intelligent chatbot support. The platform combines modern Artificial Intelligence technologies with agriculture to provide faster disease prediction, smart farming guidance, and an improved digital farming experience.

📖 Introduction

KrishiNetra is a modern AI-driven agriculture assistant designed to improve crop health monitoring and smart farming practices. The system allows users to upload crop leaf images and instantly receive disease predictions using a trained MobileNetV2 Deep Learning model.


Along with disease detection, the platform also provides weather-based farming guidance and an AI-powered chatbot that helps farmers with agricultural queries, disease awareness, and crop management support.


The platform is designed with a modern and responsive web interface that makes the system easy to use for farmers and agricultural users.

🎯 Project Objective

The main objective of KrishiNetra is to bridge the gap between Artificial Intelligence and agriculture by providing farmers with an intelligent, accessible, and user-friendly digital farming solution.

  • 🌿 Reduce crop damage and disease spread
  • 🤖 Promote AI-driven smart farming solutions
  • 📷 Enable fast and accurate disease prediction
  • 🌦 Provide weather-aware farming assistance
  • 💬 Offer AI chatbot support for farmers
  • 📚 Improve disease awareness and crop management

⚙️ How KrishiNetra Works

📤 Upload Image

User uploads crop leaf image through the web application interface.

🧠 AI Processing

Image is preprocessed and analyzed using MobileNetV2 CNN model.

🔍 Disease Detection

AI predicts the disease category with optimized accuracy.

📋 Smart Assistance

System displays prediction results, chatbot assistance, and weather-based farming guidance.

🚀 Technologies Used

🌶 Flask

Lightweight Python backend framework used for routing, server-side processing, and AI model integration.

🕸 MobileNetV2

Deep Learning CNN architecture optimized for accurate plant disease detection and classification.

🤖 TensorFlow / Keras

Used for training and deploying the AI model using transfer learning techniques.

💻 HTML • CSS • JavaScript

Used to build responsive frontend interfaces with modern glassmorphism UI design.

📸 OpenCV

Used for image preprocessing, resizing, normalization, and input handling.

📊 NumPy & Pandas

Used for dataset processing, numerical operations, and machine learning data handling.

🤖 AI Disease Detection
